# DocuMind AI — Assets Directory

This directory stores visual assets and branding elements for DocuMind AI.

## Structure

- `logo/`: Contains primary developer and product logos.
  - Recommended filename: `logo.png` or `logo.svg`.
  - Dimensions: Square aspect ratio (minimum 256x256 px, recommended 512x512 px or higher).
  - Background: Transparent PNG or high-contrast dark theme compatible.
  - The application automatically checks `assets/logo/logo.png` and falls back cleanly to a typographic brand mark if no logo file exists.
- `illustrations/`: Visual graphics, architectural diagrams, and feature previews.

## Guidelines
- Never check in copyrighted or uncredited graphic assets.
- Keep file sizes optimized for fast web application delivery.
