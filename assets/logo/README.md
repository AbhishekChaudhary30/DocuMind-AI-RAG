# Logo Assets

Place your custom developer or application brand logo in this directory.

Supported filenames (searched in order of precedence):
1. `logo.png`
2. `logo.svg`
3. `logo.jpg` / `logo.jpeg`

If no logo is present, DocuMind AI automatically displays an elegant typographic brand mark ("DocuMind AI") with violet/cyan accent styling, guaranteeing no broken image icons are ever shown.
